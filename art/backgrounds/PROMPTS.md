# Archived realistic experiments — not used by the game

Generated with the built-in imagegen tool on 2026-09-05. Archived assets are in `art/backgrounds/unused-realistic`; originals remain in the generator output folder.

This archived experiment used the existing far / mid / near parallax pipeline. See README.md for the current stylized implementation. Far layers are opaque; mid and near use genuine PNG alpha. Native aspect ratios are preserved by the renderer, and alternating mirrored tiles avoid hard edge seams. Decode uses half resolution and the existing limited biome cache. Desert dusk and storms keep their existing artwork and baked-sun handling.
